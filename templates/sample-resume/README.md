# Sample 简历（默认优化方向样本）

> **来源**：**完全虚构**的写法范式样本（学校/公司/项目/外链均为示例占位，不对应任何真实个人）。用于展示「真实经历该怎么组织」，不是某份真实简历的脱敏稿。

## 为什么放这个样本

高质量简历的核心范式（**默认优化方向**）：

```
每个经历 = 在什么岗位/角色工作 → 工作范围是什么 → 有什么产出（量化） → 如何持续迭代优化
```

**特别值得学的：持续化优化思路**——每个项目不只写"做了什么"，还写**迭代演进**：
- Agent 系统：从"过度复杂"到"简单清晰"的两代架构演进（展示架构决策与减法能力）
- 信息管道：找→拿→拆→存 四段自动化（展示系统设计与 scale 能力）
- 播客/内容：从数十人到 1000+ 听众（展示增长与迭代）

## 使用方法

1. **默认方向**：agent 组织用户简历时，参照这个范式（岗位→范围→量化产出→迭代）
2. **用户可改**：用户可以说"我更喜欢另一种写法/布局/重点"，agent 按用户偏好调整
3. **不照抄内容**：这是结构参考，内容永远用用户自己的真实素材
