# Sample 简历（默认优化方向样本）

> **来源**：基于一份**真实实习求职简历**的脱敏改写——**保留真实经历的内容与量化细节**（岗位/职责/产出数据/方法论），仅将可识别身份的实体（学校/公司名/具体人名）替换为通用表述（`{学校}` / 某机构 / 某媒体）。**展示"真实经历该怎么组织"的最佳实践**。

## 为什么放这个样本

高质量简历的核心范式（**默认优化方向**）：

```
每个经历 = 在什么岗位/角色工作 → 工作范围是什么 → 有什么产出（量化） → 如何持续迭代优化
```

**特别值得学的**（来自真实实践）：
- **实习经历**：职责 + 量化产出（播放量 125 万+ / 阅读 10 万+ / 听众 20→1000+）+ 方法论（R 语言 Pipeline、素材管理系统）
- **持续化优化思路**：Agent 系统从"过度复杂"到"简单清晰"的两代架构演进（展示架构决策与减法能力）
- **能力多素材支撑**：每个能力下有多个具体案例（文化分析 5 篇、投资笔记 4 篇）

## 使用方法

1. **默认方向**：agent 组织用户简历时，参照这个范式（岗位→范围→量化产出→迭代）
2. **用户可改**：用户可以说"我更喜欢另一种写法/布局/重点"，agent 按用户偏好调整
3. **不照抄内容**：这是结构参考，内容永远用用户自己的真实素材

## 文件

- `sample-resume.html` — 渲染版（含脱敏实习经历/技能，A4 苹果风）
- `sample-resume.md` — 内容源（结构化）
- `photo.jpg` — 几何抽象占位头像（非真人照片；用户替换为自己的照片）

## 隐私说明

样本中的公司/学校名已替换为通用表述，**不含可识别到具体个人的信息**；量化数据与职责描述为真实经历的呈现（这是"怎么写好"的示范），使用时应替换为用户自己的真实经历。
