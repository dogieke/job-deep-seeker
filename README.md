# job-deep-seeker

> 全自动求职投递流水线（实习 / 全职 / 校招均适用）— 目标驱动，不绑定任何工具，集成opendesign 简历模板和风格，自动根据岗位输出成熟适配简历。

一个给 **Agent** 用的求职投递 Skill：自动寻找岗位信息 → 确认投递方向 → 整理素材 → 生成定制简历 → 自动邮箱投递 → 记录跟进。


## 核心流程

```
① 找岗位（多来源并行） → ② 素材整理（用户协作） → ③ 组合简历（模板驱动）
 → ④ 投递（邮箱直投） → ⑤ 记录 + 跟进 + 沉淀
      └────── Self-Refine 自检贯穿 ──────┘
```

## 特性

- **目标驱动**：流程固定（5 阶段），工具不固定（agent 自探测）
- **不写死**：不绑定任何浏览器/邮件/PDF 工具，agent 按环境发现替代品
- **反爬纪律**：社交平台采集用「截图 + 视觉模型转写」，不爬取
- **简历模板 + 风格分离**：默认模板（A4 单页苹果风）+ 6 种可选风格（苹果/极简/小红书/复古/商务/创意）
- **错题本机制**：每轮执行的经验沉淀到 log.md，agent 下轮先读，自我迭代
- **冷启动引导**：GUIDE.md 阅后即焚，跑通一轮后删除，agent 自由发挥
- **适用范围**：实习 / 全职 / 校招 / 社招通用

## 安装

```bash
# 克隆仓库
git clone https://github.com/dogieke/job-deep-seeker.git
# 或直接下载，放到你的 Agent skills 目录（如 ~/.pi/agent/skills/）
```

## 使用

首次运行会自动引导（读 GUIDE.md），收集你的信息并确认投递方向：

```
① 提供简历材料（已有简历/作品集/项目/账号数据）
② 确认投递方向（想投什么 + 投多少封）
③ Agent 自动找岗位 → 生成定制简历 → 投递 → 跟进
```

**首次运行会问你**：
- 这轮想投多少个岗位？（N）
- 有没有特定渠道/平台？

## 隐私与运行产物（重要）

本 skill 会处理**简历、邮箱、电话、投递记录**等敏感数据。请注意：

- **运行产物勿 push**：`log.md`、`env.json`、`.env`、`applications.jsonl`、生成的真实简历 PDF/HTML、SMTP 授权码、浏览器 profile 路径等**只留在本机**，已在 `.gitignore` 中排除常见项；开源/提交 PR 前再检查一遍
- **示例简历是虚构的**：`templates/sample-resume/` 与模板占位内容不对应任何真实个人，请用你自己的素材替换
- **投递与账号操作**：批量邮件、登录态浏览器、第三方求职 CLI 等能力对用户有帮助，但可能触发邮箱限流、平台风控或账号限制——按你的接受度使用，首封测试、小批量推进更稳妥

## 给用户

1. 把你的简历材料准备好（已有简历/作品集/项目数据）
2. 跑一轮完整的流程（找岗位→投递）
3. 投递后定期看收件箱，回复会沉淀到 log.md 供下轮参考

## 给贡献者

### 开发流程

1. Fork 本仓库，改 `SKILL.md`（方法论）或 `templates/`（资源）
2. 保持设计原则：**不写死环境**——新内容只描述【目标】和【经验】，不绑定具体工具
3. 提交信息格式：`类型: 简述`（如 `feat: 增加X风格` / `fix: 修正错题本格式`）

### 贡献指南

- **SKILL.md**：只放方法论与通用经验；环境细节放错题本 log.md（不公开）或 GUIDE.md（冷启动）
- **templates/**：新增模板/风格时注明来源与版权（Apache-2.0）
- **经验贡献**：跑完一轮后，把踩过的坑提交到 log.md（带日期/问题/修复/适用阶段），或开 PR 建议加入正文

## 安全与合规

使用本 skill 时请注意：

- **敏感数据不入库**：真实简历、邮箱授权码、SMTP 凭据、投递记录（applications.jsonl）**禁止提交到 git**——`log.md` 已被 .gitignore 排除，勿改动该规则
- **投递需用户确认**：批量邮件发送前必须让用户确认岗位名单与文案；发送频率控制（间隔几秒、分批），避免触发垃圾邮件判定/邮箱限流
- **不违反平台 ToS**：不爬取有反爬/禁止自动化条款的平台；社交平台采集用「截图 + 视觉模型转写」（反爬纪律），且仅限用户已登录授权
- **文件系统扫描限范围**：素材扫描仅限用户指定的目录，不越权读取无关文件
- **登录态浏览器**：使用用户已登录的浏览器 profile 操作，注意账号安全（误操作有封号风险），异常时立即停止
